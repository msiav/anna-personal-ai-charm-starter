# Security policy

This is an early-stage community starter, not a security-audited product. Do not use it to store credentials or sensitive information without reviewing and adapting the code for your needs.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. If GitHub offers private vulnerability reporting for this repository, use that channel. Otherwise, contact the maintainer through the GitHub profile and ask for a private reporting route before sharing technical details.

Please include the affected revision, impact, and a minimal reproduction. Do not include real API keys, signing certificates, private conversations, or other users' data. The maintainer will work to acknowledge reports and coordinate a fix, but no response-time guarantee is made.
